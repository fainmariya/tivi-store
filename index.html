BEHIND THE PROJECT

How We Work

TIVI Store is a collaborative project developed by two RS School students using Vanilla TypeScript, HTML, CSS, and Vite.

We organize our work through GitHub Projects, where tasks are assigned to team members and tracked from planning to completion.

Our development workflow includes feature branches, Pull Requests, and mutual code reviews. We discuss implementation decisions, share feedback, and improve the project together.
